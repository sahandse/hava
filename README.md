# هوا 🌦️

اپلیکیشن هواشناسی فارسی برای Android با Flutter.

## هدف
- رابط فارسی و RTL
- تقویم شمسی
- داده واقعی هواشناسی
- پیش‌بینی ساعتی و ۱۰ روزه
- کیفیت هوا، UV، باد، بارش، طلوع و غروب
- هشدارها، نقشه/رادار و ویجت اندروید
- Light / Dark
- بدون داده دمو

## منبع داده نسخه اول
Open-Meteo

## وضعیت
فاز ۱: معماری، Design System و صفحه خانه.
